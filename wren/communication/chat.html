Credentials never leave this machine and are never shown here — only whether each one is configured. Manage them in a terminal on the host Wren runs on:

./manage.sh secret list
./manage.sh secret set KEY

Restart Wren afterwards (./manage.sh restart) — credentials are read at startup.
