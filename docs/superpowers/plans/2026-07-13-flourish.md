# Cute Emote Flourish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wren's 12 success-confirmation messages get a random bird/cute-themed emoji suffix (e.g. "Saved. 🐦"), via a shared `flourish()` helper — everything else (errors, guards, empty-states, listings, LLM/chat content, `pin_note`'s own text) stays exactly as-is.

**Architecture:** One new module, `wren/flourish.py`, exporting `flourish(text: str) -> str` and a public `EMOTES` list. Twelve call sites across `wren/bot.py`, `wren/shopping_plugin.py`, `wren/notes_plugin.py`, `wren/pins_plugin.py`, `wren/reminder_plugin.py`, `wren/contacts_plugin.py` wrap their existing confirmation string in `flourish(...)`. No other logic changes anywhere.

**Tech Stack:** Python 3.11+, stdlib `random`, `pytest`. No new dependencies.

## Global Constraints

- Exactly these 12 messages get flourished, nothing else: `send_to_person`'s "Sent to {name}." (bot.py); `add_shopping_item`'s "Added {item}.", `remove_shopping_item`'s "Got it, removed {item}.", `send_shopping_list`'s "Sent to {name}." (shopping_plugin.py); `save_note`'s "Saved.", `save_idea`'s "Saved that idea.", `discard_idea`'s "Discarded: {content}." (notes_plugin.py); `unpin_note`'s "Unpinned: {content}" (pins_plugin.py); `set_reminder`'s "Reminder set for {time}.", `cancel_reminder`'s "Cancelled: {content}." (reminder_plugin.py); `add_contact`'s "Added {alias}.", `remove_contact`'s "Removed {alias}." (contacts_plugin.py).
- `pin_note`'s content send, all listings/loops, LLM-generated replies (chat, web summaries, expand_idea), and every error/guard/empty-state message are never wrapped in `flourish()`.
- `EMOTES` is a public module-level list (not `_EMOTES`) so tests can assert membership.
- No new dependencies.

```python
from wren.flourish import flourish, EMOTES

def test_flourish_appends_a_space_and_an_emote():
    result = flourish("Saved.")
    assert result.startswith("Saved. ")
    trailing = result.rsplit(" ", 1)[1]
    assert trailing in EMOTES

def test_flourish_preserves_original_text_exactly():
    result = flourish("Cancelled: check the oven.")
    prefix = result.rsplit(" ", 1)[0]
    assert prefix == "Cancelled: check the oven."

def test_flourish_uses_more_than_one_emote_across_many_calls():
    seen = {flourish("x").rsplit(" ", 1)[1] for _ in range(200)}
    assert len(seen) > 1
```

Expected: FAIL (`ModuleNotFoundError: No module named 'wren.flourish'`)

- [ ] **Step 3: Write the implementation**

Create `wren/flourish.py`:

```python
import random

EMOTES = ["🐦", "🐦‍⬛", "🪶", "🐤", "🐣", "✨"]

def flourish(text: str) -> str:
    return f"{text} {random.choice(EMOTES)}"
```
