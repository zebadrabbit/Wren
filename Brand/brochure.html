What it does

No commands to learn. Say it the way you'd say it.

Wren works out what you meant and files it in the right place. Every line below is something you can type or say as written.

Shopping lists

One shared list for the house, and any other list you name.

  • add potatoes to shopping
  • add a tent to the packing list
  • got the potatoes
  • put the milk back
  • send shopping to hubby

Reminders and timers

One-off, repeating, or just a countdown. Wren messages you when they're due.

  • remind me to take out the trash at 6pm
  • every tuesday at 8pm remind me to water the plants
  • timer 20 minutes
  • how long is left
  • cancel the trash reminder

Daily briefing

Weather, calendar, today's reminders and the list in one message. Set a time and it arrives each morning on its own.

  • what's my day look like
  • what's on my calendar
  • will it rain tomorrow
  • my location is 72715

Notes and ideas

Jot things down, keep ideas to come back to, and export all of it as a Markdown file.

  • note: call the plumber
  • remember this idea: build a treehouse
  • expand on the treehouse idea
  • send my notes as a markdown file

Ask about anything you told it

Questions search your notes, reminders, calendar and what Wren has picked up about you, and the answer says where it came from.

  • what did I say about the dentist
  • what do you know about me
  • forget that I like mushrooms

Photos and PDFs

Send a file with a caption to save it as a note. Ask a question about a picture, or have it read a list off one.

  • what plant is this?
  • add these
  • receipt for the new fridge
Picture questions need a model that can see images.

Pins

The things you look up every week, kept where you can find them.

  • pin: wifi password is 12345
  • what's pinned
  • unpin the wifi one

Messages to the family

Pass a message to someone in the house, on whichever app they use.

  • tell hubby dinner's at 7
  • add 987654321 as hubby on telegram
  • who's whitelisted

Web lookups

Searches through your own SearXNG instance and summarises with links. It can read a page in full when you ask.

  • any news on the port strike
  • read me the first one
  • read https://…

Your data stays home

It lives on your machine.

One SQLite fileNotes, lists, reminders and memories sit in a single database on your disk. Back it up by copying it.
A local model by defaultBuilt and tested on Gemma 4 through Ollama or LM Studio. OpenAI, Claude or OpenRouter can be added as fallbacks if you want them.
Speech-to-text on the boxThe desktop voice client is transcribed with Whisper on your own machine.
Hard to get wrong

Mistakes are easy to take back.

“undo that”Removed, cleared, cancelled or forgot the wrong thing? Undo works for ten minutes afterwards.
Voice asks firstAnything spoken that would delete something gets a yes-or-no question before it happens.
Only people you addWren answers the owner and the contacts they approve. Settings and skills are switched on and off by the owner.
Get started

Runs on the machine you already leave on.

Python, one config file, and a model. Turn on only the channels and skills you want. New skills are a single file.

# clone and install
git clone https://github.com/zebadrabbit/Wren
cd Wren && python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt

# pick your channels and model
cp .env.example .env

python3 -m wren.run
